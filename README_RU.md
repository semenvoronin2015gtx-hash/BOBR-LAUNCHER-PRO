# BOBR LAUNCHER PRO — стартовый Android-проект

Это **первая интерфейсная версия** лаунчера на Kotlin + Jetpack Compose.

## Что уже есть
- Главная страница и нижняя навигация
- Выбор версии Minecraft (список-прототип)
- Разделы модов и ресурспаков
- Профиль-заглушка
- Настройка RAM в интерфейсе

## Важно
Это пока **не готовый игровой лаунчер**: Minecraft Java не запускается, версии не скачиваются, моды не устанавливаются, а ползунок RAM пока только демонстрационный. Для настоящего запуска нужно интегрировать игровой движок Android (например, Amethyst) и реализовать загрузку библиотек/версий и официальный вход Microsoft. Не вводите пароль Microsoft в самодельные формы.

## Сборка APK
1. Откройте проект в Android Studio на компьютере.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/`.
